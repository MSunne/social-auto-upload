# OmniBull 恢复 U 盘操作说明

## 1. 先做什么

1. 将恢复 U 盘插入待量产设备。
2. 开机进入 BIOS 或启动菜单。
3. 选择从该 U 盘启动。
4. 在启动菜单中选择 `OmniBull Factory Restore`。

## 2. 恢复系统

1. 等待恢复程序启动。
2. 确认目标硬盘无误。
3. 按提示确认目标盘。
4. 恢复会自动开始，不再要求输入 `RESTORE`。
5. 等待整盘恢复完成。
6. 恢复完成后，拔出 U 盘并重启。

## 3. 首次开机

1. 设备会自动进入桌面并自动登录 `sun`。
2. 不要手动关闭 OmniBull。
3. 等待设备自动连接 OmniDrive。
4. 在云端确认设备状态为“在线、未认领”。

## 4. 云端认领

1. 打开 OmniDrive 云端页面。
2. 找到该设备。
3. 输入 `activationCode` 完成认领。

## 5. 记住这三点

- 恢复会清空目标硬盘全部数据。
- 必须选择 `OmniBull Factory Restore`，不要进入普通安装或试用界面。
- 云端输入的是 `activationCode`，不是 `deviceCode`。
